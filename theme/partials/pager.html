When the target page is in another top-level section, its title is prefixed with that section ("API › Overview"), so that a generic title such as "Overview" is not ambiguous. {%- if page.previous_page %} Previous {{ pager_title(page.previous_page) }} {%- endif %} {%- if page.next_page %} Next {{ pager_title(page.next_page) }} {%- endif %}
