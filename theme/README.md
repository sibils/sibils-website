# SIBiLS MkDocs theme

A standalone MkDocs theme for sibils.org (`theme: {name: null, custom_dir: theme}` in
`mkdocs.yml`). It needs no theme package, no CDN and no build step: run `./serve` from the
repository root and edit the files; the preview reloads (`watch` in `mkdocs.yml`). The look follows the SIBiLS web applications: red band with the white wordmark,
white sub-bar with the documentation sections.

## Files

| Path | Role |
|------|------|
| `main.html` | Layout of every documentation page: section sidebar, breadcrumb, content, previous/next, "On this page" |
| `home.html` | Home page (`template: home.html` in `docs/index.md`): intro band from the front matter, collection counts, content |
| `404.html` | "Page not found" (a static template, see `static_templates` in `mkdocs.yml`) |
| `partials/head.html` | `<title>` (the page's H1), description (front matter, else the `{ .lead }` paragraph, else the site's), canonical URL, Open Graph and Twitter cards, icons, the script that applies the light/dark theme before the first paint |
| `partials/jsonld.html` | schema.org description of SIBiLS, home page only. Its service channels are the SIBiLS apps of `extra.apps` |
| `partials/header.html` | Red band: the wordmark, a link to the home page. Unlike the apps' own band, it does not list the SIBiLS apps: the Services section, the home page and each service page link to them |
| `partials/subbar.html` | Site title, the top-level nav sections, search button, theme toggle, menu button (below 1024 px) |
| `partials/sidebar.html`, `toc.html`, `breadcrumb.html`, `pager.html` | Navigation around the content |
| `partials/drawer.html`, `search.html` | The menu and search dialogs (`<dialog>`); `search.html` also lists each page's H1 and sections for the search results |
| `partials/counts.html` | Home page collection counts: a round lower bound of each count from `config.extra.sibils` (set by `hooks/sibils_data.py`), in grey and read as "at least …" by screen readers, until `js/counts.js` replaces it |
| `partials/footer.html` | Partner logos (`extra.partners`), licence, contact, source link |
| `partials/analytics.html` | Matomo (`extra.analytics`), only on sibils.org and www.sibils.org |
| `partials/macros.html` | Navigation helpers, URL resolution for front-matter links, icons |
| `css/sibils.css` | All styles: colour tokens (light and dark), layout, content components, print |
| `css/pygments.css` | Syntax colours, generated by `tools/build_pygments_css.py` |
| `js/theme.js` | Theme toggle, menu drawer, copy buttons, table wrappers, current section in "On this page" |
| `js/search.js` | Search dialog over `search/search_index.json` (written by the MkDocs `search` plugin) |
| `js/counts.js` | Home page only (loaded by `partials/counts.html`): reads the current counts from the SIBiLS API (`config.extra.sibils.count_url`) and writes the exact numbers in place of the approximate ones. See "Collection counts" below |
| `fonts/` | DM Sans variable font (latin and latin-ext, normal and italic), licence in `fonts/OFL.txt` |
| `img/` | Wordmarks, favicon, Apple touch icon, social card (`og-card.png`), `partners/` logos |
| `tools/build_pygments_css.py` | Regenerates `css/pygments.css` and checks its contrast |

MkDocs copies every file of this folder to the site except templates (`*.html`), Python files and
this README.

## Navigation rules

- The sub-bar lists the top-level entries of `nav`; a section links to its first page.
- The left sidebar lists the pages of the current top-level section. A top-level page without a
  section (Overview, Publications) has no sidebar.
- A nav section whose first child is a page **without a title** (for example
  `- api/biodiversitypmc/index.md` under "BiodiversityPMC") uses that page as its landing page:
  the section label links to it and the page is not listed again.
- "On this page" appears when a page has at least two `##` headings and the window is at least
  1200 px wide. Its column is reserved on every page, so the main column has the same width and
  position on all pages.
- Front matter `hide: [navigation]` and `hide: [toc]` remove the sidebar or "On this page".
- Wide pages (`layout is-wide`): no "On this page" column and a main column up to the full
  width (layout up to 1600px). Automatic for pages containing `<swagger-ui`; front matter
  `wide: true` / `wide: false` overrides it. Paragraphs keep their 40rem reading width.
- The ids of theme elements start with `__` (`__content`, `__search-dialog`...), so that they
  cannot collide with the ids of headings (a `## Content` heading gets `id="content"`).

## Colours

Colour tokens are CSS custom properties at the top of `css/sibils.css`, once for light and twice for
dark (the `data-theme="dark"` attribute set by the toggle or the system preference, and the system
preference alone for visitors without JavaScript). Text colours are at least 4.5:1 on their
backgrounds and borders that identify a control at least 3:1. If you change a token, check the
pairs again; `tools/build_pygments_css.py` does it for the code colours:

    ./venv/bin/python theme/tools/build_pygments_css.py

## Collection counts

The home page is built with approximate counts: each count of the build, rounded down to two
significant digits (`approximate()` in `hooks/sibils_data.py`), in the `--approx-ink` grey
(at least 4.5:1 on the intro band, in light and dark), with a visually hidden "at least " before
it. `js/counts.js` then fetches `count_url` once: a simple CORS GET (no custom header, so no
preflight), without cookies, timeout 3 seconds. For each collection whose count is an integer
not below `data-min` (`live_min`: half the round number, so a 0 or a partial count is not shown)
it writes the exact number (`Intl.NumberFormat('en-US')`, the format of the build) and removes
the grey and the hidden text, at once (no transition). Anything else (no answer, HTTP error,
CORS refusal, invalid JSON, `success` not `true`, a missing or invalid count) leaves the
approximate values: no message, no retry, no `aria-live` announcement. DM Sans has no tabular
figures and its "0" is wide, so the round numbers are a little wider than the exact ones. Where
the numbers are right-aligned, the number fills the rest of its line; from 640 to 1023 px the
five columns are equal (`flex: 1 1 6.5rem`) and never narrower than their text, so a larger text
size or text spacing wraps the row instead of making the numbers overlap. In both layouts the
exact number does not move the layout. No other page loads the script.

## Updating the font

The woff2 files come from the `@fontsource-variable/dm-sans` npm package (`files/*-wght-*.woff2`),
which repackages the Google Fonts build of DM Sans:

    npm pack @fontsource-variable/dm-sans && tar -xzf fontsource-variable-dm-sans-*.tgz
    cp package/files/dm-sans-latin{,-ext}-wght-{normal,italic}.woff2 theme/fonts/
    cp package/LICENSE theme/fonts/OFL.txt

## Images

- `img/favicon.png` (64 x 64) and `img/apple-touch-icon.png` (180 x 180) are the SIB emblem cropped
  from the top right of `img/sibils-wordmark.png`.
- `img/og-card.png` (1200 x 630) is the preview shown when a page is shared. It is a screenshot of
  a small HTML page (red band with the white wordmark, the site description in DM Sans), taken with
  headless Chromium: `chrome --headless --window-size=1200,630 --screenshot=og-card.png card.html`.
