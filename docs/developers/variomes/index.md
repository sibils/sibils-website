# Variomes API

The Variomes API ranks the publications that mention a genomic variant, in MEDLINE, PMC, ClinicalTrials.gov and supplementary data, and returns the details of selected publications.
{ .lead }

<div class="facts" markdown>

Endpoints
:   `https://variomes.sibils.org/api/rankLit` · `https://variomes.sibils.org/api/fetchDoc`

Documentation
:   [variomes.sibils.org/apis](https://variomes.sibils.org/apis)

Web application
:   [variomes.sibils.org](https://variomes.sibils.org/), described in [Variomes](../../services/variomes/index.md)

Authentication
:   None

</div>

The [API documentation](https://variomes.sibils.org/apis) lists all the parameters: the variants (`genvars`), the disease, the patient's gender and age, the publication years, the collections (`collections=medline,pmc,ct,supp`), whether the disease, gene and variant must be mentioned or expanded with synonyms, positive and negative keywords, and the number of documents (`nb`).

## Example

Rank the publications about EGFR L858R in melanoma, up to 10 per collection:

[https://variomes.sibils.org/api/rankLit?genvars=EGFR%20%28L858R%29&disease=melanoma&nb=10](https://variomes.sibils.org/api/rankLit?genvars=EGFR%20%28L858R%29&disease=melanoma&nb=10)

The response contains `unique_id`, `settings`, `query`, `normalized_query` (the disease, gene and variant mapped to concepts, with the variant synonyms generated by [SynVar](../synvar/index.md)), `publications` (one ranked list per collection) and `errors`. On 22 November 2026, this request took about 1 second and returned 7 MEDLINE, 10 PMC, 8 ClinicalTrials.gov and 10 supplementary data documents.

`fetchDoc` returns the details of publications given by id, separated by `;`:

[https://variomes.sibils.org/api/fetchDoc?ids=27145535;31671409](https://variomes.sibils.org/api/fetchDoc?ids=27145535;31671409)
