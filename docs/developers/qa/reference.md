# Question-Answering API reference

This page embeds the interactive reference generated from the [OpenAPI description](https://qa.sibils.org/api/openapi.json) of the Question-Answering API. The same reference is available on the API server, as [Swagger UI](https://qa.sibils.org/api/). The [guide](index.md) explains the endpoints and outputs, with examples.

"Try it out" sends real requests to `https://qa.sibils.org/api`. `GET /fetch` declares no parameters in the description, so it cannot be tried here: use the example URL in [GET /fetch](index.md#get-fetch).
