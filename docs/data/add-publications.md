# Add your publications

Publishers can deposit their publications on the SIBiLS FTP server to have them indexed and annotated in [BiodiversityPMC](../services/biodiversitypmc/index.md). Supplementary files deposited with an article go into the [supplementary data collection](collections.md#supplementary-data).
{ .lead }

## Procedure

1. Fill in the [SIBiLS contract (Word)](../collections/contract/SIBiLS_contract.docx) and send it to [julien.gobeill@hesge.ch](mailto:julien.gobeill@hesge.ch).
2. You receive a login and password for the SIBiLS FTP server, where you have your own directory.
3. Upload your articles:
    * JATS XML is the recommended format. For other formats, such as PDF, contact the SIBiLS team by email first.
    * If an article has supplementary files, put the article and its files in one tar.gz archive (recommended).
    * You can add, update or delete any article, and create subdirectories so that no directory holds too many files.

SIBiLS checks the FTP server every day and updates the collection.
